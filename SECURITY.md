# Security Policy

## Supported Versions

This project has not yet had a tagged release; security fixes are made
against the latest commit on `main`.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/onfranciis/OID/security) of this repository.
2. Click **"Report a vulnerability"**.
3. Include as much detail as you can: affected component/endpoint, steps to
   reproduce, and potential impact.

You should expect an initial response within a few days. If the report is
confirmed, a fix will be prepared privately and disclosed once it's available.

If private reporting isn't enabled on the repository yet, please contact the
maintainer, [@onfranciis](https://github.com/onfranciis), directly instead of
filing a public issue.
